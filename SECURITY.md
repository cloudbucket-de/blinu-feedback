# Sicherheit / Security

## Deutsch

Bitte melde Sicherheitslücken **nicht** öffentlich als Issue oder Discussion.

Nutze stattdessen die vertrauliche Meldung von GitHub:
[Sicherheitslücke melden](https://github.com/cloudbucket-de/blinu-feedback/security/advisories/new)

Alternativ per E-Mail an [support@blinu.app](mailto:support@blinu.app). Beschreibe, was betroffen ist und wie man es nachvollziehen kann. Wir melden uns so schnell wie möglich.

## English

Please do **not** report security vulnerabilities as a public issue or discussion.

Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/cloudbucket-de/blinu-feedback/security/advisories/new)

Alternatively, email [support@blinu.app](mailto:support@blinu.app). Describe what is affected and how to reproduce it. We will get back to you as soon as possible.
