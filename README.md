# Blinu – Feedback

[Deutsch](#deutsch) · [English](#english)

## Deutsch

Hier sammeln wir Fehlermeldungen und Ideen für [Blinu](https://blinu.app), die native macOS-App für SSH-Terminals, Server-Monitoring mit Alarmen und einen KI-Assistenten. Der Quellcode der App liegt nicht in diesem Repository.

### Fehler melden

[Neuen Bug melden](https://github.com/cloudbucket-de/blinu-feedback/issues/new?template=bug.yml) – oder in Blinu über das Menü **Hilfe**, dann sind Version, macOS und Architektur schon ausgefüllt. Bitte prüfe vorher, ob der Fehler schon gemeldet wurde.

Hast du einen Absturzbericht, kannst du ihn im Formular anhängen. Das ist freiwillig: Blinu sendet nichts automatisch, Berichte bleiben lokal auf deinem Mac.

### Ideen und Feature-Wünsche

Ideen gehören in die [Discussions → Ideas](https://github.com/cloudbucket-de/blinu-feedback/discussions/categories/ideas). Beschreibe das Problem, deinen Vorschlag und mögliche Alternativen.

### Support

Persönliche Fragen (Lizenz, Konto, Hilfe): [support@blinu.app](mailto:support@blinu.app)

Sicherheitslücken bitte vertraulich melden, siehe [SECURITY.md](SECURITY.md).

### Was du nicht posten solltest

Issues und Discussions sind öffentlich. Entferne oder ersetze vorher:

- Hostnamen und Domains deiner Server
- IP-Adressen
- Benutzernamen
- Schlüssel, Passwörter, Tokens und andere Zugangsdaten

Nutze Platzhalter wie `server.example.com`, `203.0.113.10` und `user`.

Sprachen: Deutsch und Englisch.

## English

This is where we collect bug reports and ideas for [Blinu](https://blinu.app), the native macOS app for SSH terminals, server monitoring with alarms and an AI assistant. The app's source code is not in this repository.

### Report a bug

[Report a new bug](https://github.com/cloudbucket-de/blinu-feedback/issues/new?template=bug.yml) – or use the **Help** menu in Blinu, which prefills version, macOS and architecture. Please check first whether the bug was already reported.

If you have a crash report, you can attach it in the form. This is optional: Blinu sends nothing automatically, and reports stay local on your Mac.

### Ideas and feature requests

Ideas belong in [Discussions → Ideas](https://github.com/cloudbucket-de/blinu-feedback/discussions/categories/ideas). Describe the problem, your proposal and possible alternatives.

### Support

Personal questions (licensing, account, help): [support@blinu.app](mailto:support@blinu.app)

Please report security vulnerabilities privately, see [SECURITY.md](SECURITY.md).

### What not to post

Issues and discussions are public. Remove or replace before posting:

- host names and domains of your servers
- IP addresses
- user names
- keys, passwords, tokens and other credentials

Use placeholders such as `server.example.com`, `203.0.113.10` and `user`.

Languages: German and English.
